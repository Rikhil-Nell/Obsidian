## Interesting Problems

### Agentic Loan Origination (Penny)

AI agent handles borrower guidance through intake, document verification, and delivers complete loan files for underwriters. End-to-end workflow automation in a regulated domain — high correctness bar, document parsing, state machines across loan lifecycle.

### Document Verification at Scale

Mortgage = dense paperwork, error-prone manual review. Agent must verify docs, catch inconsistencies, reduce drowning-in-paperwork problem lenders describe. Similar tension to Oximy: **silent errors vs hard failures** in high-stakes data.

### Democratizing Mortgage Access

Founders frame better lender tooling → better borrower experience → broader access to homeownership. Product + mission, not pure infra play.

### Regulated Domain + Speed

Athan holds Mortgage Loan Originator License (NMLS #2805691) — unusual for a CEO, signals domain commitment. Building fast in regulated fintech is hardcore-engineer territory.
