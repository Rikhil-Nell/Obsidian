# 🇩🇪 GERMAN EXAM PROTOCOL: THE CHEATSHEET

### 1. NUMBERS (Zahlen)
**Rule:** For 21-99, say "One-and-Twenty".

| Number | German | Logic |
| :--- | :--- | :--- |
| **1-12** | eins, zwei, drei... zwölf | Memory |
| **13-19** | [Number] + zehn | dreizehn (3+10) |
| **20, 30...** | zwanzig, dreißig, vierzig... | -zig ending (-ßig for 30) |
| **21-99** | [Unit] + und + [Ten] | **ein**undzwanzig (21) |
| **Example** | **33** | dreiunddreißig |

---

### 2. ARTICLES (Artikel)
**Goal:** Match the gender.

| Gender | Definite (The) | Indefinite (A/An) |
| :--- | :--- | :--- |
| **Masculine** | Der | Ein |
| **Feminine** | Die | Eine |
| **Neuter** | Das | Ein |
| **Plural** | Die | - |

---

### 3. VERB CONJUGATION (Endings)
**Goal:** Match Subject to Ending.

| Subject | Ending | Example (Wohnen) |
| :--- | :--- | :--- |
| **Ich** | -e | Ich wohn**e** |
| **Du** | -st | Du wohn**st** |
| **Er / Sie / Es** | -t | Er wohn**t** |
| **Wir** | -en | Wir wohn**en** |
| **Ihr** (You pl) | -t | Ihr wohn**t** |
| **Sie** (Formal/They)| -en | Sie wohn**en** |

**⚠️ DANGER ZONES:**
* **Sprechen (Strong):** *Du* **sprichst**, *Er* **spricht**. (Change e -> i).
* **Mögen (Modal):** *Ich* **mag**, *Er* **mag**. (Irregular!).

---

### 4. POSSESSIVE PRONOUNS
**Rule:** Add **-e** if the owned item is **Die** (Feminine/Plural).

| Owner | Stem | If Item is Der/Das | If Item is Die (Fem/Plural) |
| :--- | :--- | :--- | :--- |
| **Ich** | mein | mein Vater | mein**e** Mutter |
| **Du** | dein | dein Vater | dein**e** Mutter |
| **Er / Es** | sein | sein Vater | sein**e** Mutter |
| **Sie (She)** | ihr | ihr Vater | ihr**e** Mutter |
| **Wir** | unser | unser Vater | unser**e** Mutter |
| **Ihr (You pl)** | euer | euer Vater | euer**e** Mutter |
| **Sie (They)** | ihr | ihr Vater | ihr**e** Mutter |

---

### 5. SYNTAX (The Golden Rules)
**Rule 1: V2 Rule**
The **Conjugated Verb** is ALWAYS the **2nd Idea**.
* ✅ *Ich **wohne** in Berlin.*
* ✅ *Am Montag **spiele** ich Tennis.* (Time first -> Verb -> Subject).

**Rule 2: W-Questions vs. Yes/No**
* **W-Word:** *Was **machst** du?* (Verb is 2nd).
* **Yes/No:** ***Kommst*** *du aus Indien?* (Verb is 1st).

---

### 6. TIME (Uhrzeit)
**Goal:** Informal / Spoken.

| Concept | German Word | Example (For 5:XX) |
| :--- | :--- | :--- |
| **Quarter Past** | Viertel nach | *Viertel nach fünf* (5:15) |
| **Half** | Halb (+ Next Hour) | ***Halb sechs*** (5:30) |
| **Quarter To** | Viertel vor | *Viertel vor sechs* (5:45) |
| **Exact** | Uhr | *Es ist fünf Uhr.* |

---

### 7. PREPOSITIONS (Crucial)
**Goal:** Don't mix up Time and Place.

| Prep | Use Case | Example |
| :--- | :--- | :--- |
| **UM** | Clock Time | *Um* 8 Uhr |
| **AM** | Days / Weekend | *Am* Montag / *Am* Wochenende |
| **IM** | Months / Seasons | *Im* Juli / *Im* Sommer |
| **IN** | Location (Living) | Ich wohne *in* Indien |
| **AUS** | Origin (Coming from) | Ich komme *aus* Indien |

---
