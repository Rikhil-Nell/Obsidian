# 10 - Waveform Generators (Square, Triangular, Sawtooth)

## Learning Objectives
- Derive the frequency of a square wave generator (astable multivibrator using op-amp)
- Understand how a triangular wave is generated from a square wave using integration
- Explain the sawtooth wave generator circuit with rapid discharge
- Calculate output frequencies and amplitudes for each generator type

## Ground-Up Explanation

### Square Wave Generator (Astable Multivibrator)

This circuit is also called a **free-running multivibrator** -- it oscillates continuously without an external trigger.

**Analogy**: Imagine a see-saw with a ball rolling back and forth. Each time the ball reaches one end, its weight tips the see-saw (output flips), sending the ball rolling to the other end. The cycle repeats forever.

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s16_img1.png]]

**Circuit components:**
- **Positive feedback** ($R_1$, $R_2$): Sets the switching thresholds via the non-inverting input
- **RC timing** ($R_F$, $C$): Capacitor charges/discharges through $R_F$, creating the timing
- **Zener diodes** (optional): Limit output amplitude ($V_Z$ instead of $V_{sat}$)

**Operation:**
1. Assume initial output = $+V_{sat}$
2. Voltage at $V^+ = +V_{sat} \cdot \frac{R_2}{R_1 + R_2} = +\beta V_{sat}$
3. Capacitor (initially at 0V) charges toward $+V_{sat}$ through $R_F$
4. When $V^-$ (capacitor voltage) exceeds $V^+$ ($+\beta V_{sat}$), output flips to $-V_{sat}$
5. Now $V^+ = -\beta V_{sat}$. Capacitor discharges toward $-V_{sat}$
6. When capacitor voltage drops below $-\beta V_{sat}$, output flips back to $+V_{sat}$
7. Cycle repeats

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s17_img1.png]]

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s17_img2.png]]

**Frequency derivation:**

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s18_img1.png]]

$$\boxed{T = 2R_FC \ln\left(\frac{1+\beta}{1-\beta}\right)}$$

$$\boxed{f = \frac{1}{T} = \frac{1}{2R_FC \ln\left(\frac{1+\beta}{1-\beta}\right)}}$$

Where $\beta = R_1/(R_1 + R_2)$.

For $R_1 = 0.86R_2$: $\beta \approx 0.462$ and $T \approx 2R_FC$, giving $f \approx 1/(2R_FC)$.

### Triangular Wave Generator

A triangular wave is generated by **integrating a square wave**. The circuit uses two stages:

1. **Stage 1 - Comparator**: Generates a square wave (similar to Schmitt trigger)
2. **Stage 2 - Integrator**: Integrates the square wave to produce a triangular wave

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s19_img1.png]]

**Operation:**
- When comparator output = $+V_{sat}$: integrator output ramps **downward** (negative slope) at rate $V_{sat}/(R_1 C_1)$
- When comparator output = $-V_{sat}$: integrator output ramps **upward** (positive slope)
- The comparator switches when the triangular wave crosses its threshold, creating a continuous triangular waveform

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s20_img1.png]]

**Frequency of oscillation:**

$$\boxed{f = \frac{R_2}{4R_1 R_3 C_1}}$$

**Peak-to-peak amplitude:**

$$\boxed{V_{pp} = 2V_{sat} \cdot \frac{R_3}{R_2}}$$

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s22_img3.png]]

### Sawtooth Wave Generator

A sawtooth waveform is like a triangular wave but with **unequal rise and fall times** -- typically a slow linear rise followed by a rapid fall (flyback).

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s23_img1.png]]

**Circuit components:**
- **Stage 1 - Integrator**: Charges the capacitor linearly (slow ramp up)
- **Stage 2 - Comparator**: Monitors the ramp voltage
- **Transistor switch** (Q2): Connected across the capacitor for rapid discharge
- **Diodes D1, D2**: Prevent excessive reverse biasing

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s23_img2.png]]

**Operation:**
1. With $V_i < 0$, capacitor charges linearly via $R_1$ -- ramp voltage $V_{oR}$ increases slowly
2. Transistors Q1, Q2 are OFF; diodes are OFF
3. When $V_{oR}$ exceeds $V_{ref}$, comparator output flips to $+V_{sat}$
4. D1, D2 turn ON; Q1, Q2 turn ON (short circuit)
5. Capacitor discharges **rapidly** through Q2 to ground -- $V_{oR}$ drops to zero quickly
6. Comparator output reverts to $-V_{sat}$, transistors/diodes turn OFF
7. Capacitor starts charging again -- cycle repeats

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-03_Reference-Material-I_s26_img1.png]]

**Applications**: Function generators, time-base generators in CROs/oscilloscopes, signal processing reference signals.

## Key Formulas Summary

| Generator | Frequency | Amplitude |
|-----------|-----------|-----------|
| Square wave | $f = \frac{1}{2R_FC\ln\frac{1+\beta}{1-\beta}}$ | $\pm V_{sat}$ (or $\pm V_Z$) |
| Triangular wave | $f = \frac{R_2}{4R_1 R_3 C_1}$ | $V_{pp} = 2V_{sat}\frac{R_3}{R_2}$ |
| Sawtooth | $f = \frac{|V_i|}{V_{ref} \cdot R_1 C}$ | 0 to $V_{ref}$ |

## Common Mistakes

1. **Square wave generator is NOT the same as 555 astable**: The op-amp version uses positive feedback + RC charging. The 555 uses internal comparators.
2. **Triangular = integrated square**: If you forget the integration step, you won't understand how the linear ramp is generated.
3. **Sawtooth asymmetry**: Rise time >> fall time. The fall is caused by transistor discharge, not RC discharge.
4. **$\beta$ in square wave formula**: $\beta = R_1/(R_1 + R_2)$, not $R_2/(R_1 + R_2)$.

## Self-Check Questions

> [!question]- How does a triangular wave generator differ from a square wave generator?
> A triangular wave generator adds an integrator stage after the comparator (Schmitt trigger). The integrator converts the square wave into a linear ramp (triangular wave).

> [!question]- What makes a sawtooth wave different from a triangular wave?
> A sawtooth has asymmetric rise and fall times: slow linear ramp up (charging) and fast snap back to zero (transistor discharge). A triangular wave has equal rise and fall times.

> [!question]- If $R_F = 10k\Omega$, $C = 0.1\mu F$, and $\beta = 0.5$, find the square wave frequency.
> $T = 2 \times 10^4 \times 10^{-7} \times \ln(1.5/0.5) = 2 \times 10^{-3} \times \ln(3) = 2 \times 10^{-3} \times 1.099 = 2.198$ ms
> $f = 1/T = 455$ Hz
