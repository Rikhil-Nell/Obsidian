# 3.2 Introduction
The design of digital integrated circuits in VLSI systems can be realized using various logic design styles, each offering different trade-offs in terms of speed, power consumption, transistor count, area, noise immunity, and design complexity.
As technology scales into deep submicron and nanometer regimes, the choice of logic style plays a critical role in determining overall system performance and energy efficiency.
Broadly, logic circuits are classified into:
Clocked (Dynamic) Logic Design
Non-Clocked (Static) Logic Design
Dr. Aruru Sai Kumar , VIT-AP

## Page 19: 3.2.1 Non Clocked Logic Design

# 3.2.1 Non Clocked Logic Design
Non-clocked logic design refers to digital circuit styles that operate without the use of a global clock signal, where the output depends solely on the instantaneous values of the input signals.
In non-clocked logic circuits, computation occurs continuously and immediately after input transitions, eliminating the need for precharge and evaluation phases.
These logic styles are typically implemented using static circuit techniques, where complementary pull-up and pull-down networks ensure full voltage swing and reliable logic levels.
Unlike clocked dynamic logic, non-clocked logic does not rely on charge storage on capacitive nodes, thereby providing better noise margins and improved robustness against leakage and charge sharing effects.
Dr. Aruru Sai Kumar , VIT-AP

## Page 20: Non Clocked Logic Design

# Non Clocked Logic Design
Non-clocked logic design generally exhibits higher reliability and simpler timing requirements, as there is no need for clock distribution, clock skew management, or synchronization constraints.
However, such logic styles may require a larger number of transistors compared to dynamic logic, especially in high fan-in implementations.
Common examples of non-clocked logic include fully complementary CMOS logic, NMOS logic, pseudo-NMOS logic, Differential Cascade Voltage Switch Logic (DCVSL), and Pass Transistor Logic.
Due to their stability, simplicity, and robustness, non-clocked logic styles are widely used in general-purpose digital circuits and low-power applications.
Dr. Aruru Sai Kumar , VIT-AP

## Page 22: 1.CMOS Logic

# 1.CMOS Logic
A static CMOS gate is a combination of two networks, called the pull-up network (PUN) and the pull-down network.
The function of the PUN is to provide a connection between the output and VDD anytime the output of the logic gate is meant to be 1 (based on the inputs).
Similarly, the function of the PDN is to connect the output to VSS when the output of the logic gate is meant to be 0.
The PUN and PDN networks are constructed in a mutually exclusive fashion such that one and only one of the networks is conducting in steady state.
In this way, once the transients have settled, a path always exists between VDD and the output F, realizing a high output (“one”) or, alternatively, between VSS and F for a low output (“zero”).
Dr. Aruru Sai Kumar , VIT-AP

## Page 24: CMOS Logic

# CMOS Logic
A transistor can be thought of as a switch controlled by its gate signal.
An NMOS switch is on when the controlling signal is high and is off when the controlling signal is low.
A PMOS transistor acts as an inverse switch that is on when the controlling signal is low and off when the controlling signal is high.
The PDN is constructed using NMOS devices, while PMOS transistors are used in the PUN.
The primary reason for this choice is that NMOS transistors produce “strong zeros,” and PMOS devices generate “strong ones”.
Dr. Aruru Sai Kumar , VIT-AP

## Page 28: CMOS Logic

# CMOS Logic
A parallel connection of transistors in the pull-up network corresponds to a series connection of the corresponding devices in the pull-down network, and vice versa.
Therefore, to construct a CMOS gate, one of the networks (e.g., PDN) is implemented using combinations of series and parallel devices.
The complementary gate is naturally inverting, implementing only functions such as NAND, NOR, and XNOR. The realization of a non-inverting Boolean function (such as AND OR, or XOR) in a single stage is not possible, and requires the addi tion of an extra inverter stage.
The number of transistors required to implement an N-input logic gate is 2N.

## Page 30: CMOS Logic

# CMOS Logic
Advantages:
1. Very Low Static Power Consumption
In steady state (logic 0 or 1), either PMOS or NMOS is OFF, so ideally no direct current flows from VDD to GND.
Power is mainly consumed during switching (dynamic power).
This makes CMOS ideal for battery-powered and portable devices.
2. High Noise Immunity
CMOS provides large noise margins.
Strong logic levels (full VDD for ‘1’ and 0V for ‘0’) reduce the chance of logic errors.
Very suitable for high-density integration.
Dr. Aruru Sai Kumar , VIT-AP

## Page 31: CMOS Logic

# CMOS Logic
3. High Input Impedance
MOSFET gates are insulated by oxide → almost zero DC input current.
Enables large fan-out capability.
Reduces loading effect on previous stages.
4. Rail-to-Rail Output Voltage
Output swings from 0 to VDD.
Ensures strong logic levels and better signal integrity.
5. High Packing Density
CMOS technology supports very small transistor sizes.
Enables integration of millions to billions of transistors on a single chip.
Essential for modern microprocessors and SoCs.
Dr. Aruru Sai Kumar , VIT-AP

1.Dynamic Power Consumption

Dynamic power:

During switching, both PMOS and NMOS may conduct simultaneously for a short time.
This creates a direct path from VDD to GND → short-circuit current.

## Page 41: 3. Pseudo-NMOS Logic

# 3. Pseudo-NMOS Logic
Ratioed logic is an attempt to reduce the number of transistors required to implement a given logic function, at the cost of reduced robustness and extra power dissipation.
The purpose of the PUN in complementary CMOS is to provide a conditional path between VDD and the output when the PDN is turned off.
In ratioed logic, the entire PUN is replaced with a single unconditional load device that pulls up the output for a high output.
Instead of a combination of active pull-down and pull-up networks, such a gate consists of an NMOS pull-down network that realizes the logic function, and a simple load device.
A ratioed logic, which uses a grounded PMOS load and is referred to as a pseudo-NMOS gate.
Dr. Aruru Sai Kumar , VIT-AP

## Page 43: Pseudo-NMOS Logic

# Pseudo-NMOS Logic
The clear advantage of pseudo-NMOS is the reduced number of transistors (N+1 versus 2N for complementary CMOS).
The nominal high output voltage (VOH) for this gate is VDD since the pull-down devices are turned off when the output is pulled high (assuming that VOL is below VTn).
On the other hand, the nominal low output voltage is not 0 V since there is a fight between the devices in the PDN and the grounded PMOS load device.
This results in reduced noise margins and more importantly static power dissipation.
Dr. Aruru Sai Kumar , VIT-AP

## Page 44: Pseudo-NMOS Logic

# Pseudo-NMOS Logic
The sizing of the load device relative to the pull-down devices can be used to trade-off parameters such a noise margin, propagation delay and power dissipation.
Since the voltage swing on the output and the overall functionality of the gate depends upon the ratio between the NMOS and PMOS sizes, the circuit is called ratioed.

# 3. Differential Current Switch Logic
Differential Current Switch Logic (DCSL) is a high-speed clocked dynamic differential logic style that generates both true and complementary outputs using a differential NMOS pull-down network and cross-coupled PMOS load devices.
DCSL operates using a clock-controlled precharge and evaluation mechanism, where output nodes are precharged during the precharge phase and conditionally discharged during the evaluation phase based on the applied input combinations.

Since DCSL relies on dynamic charge storage and eliminates static direct current paths between VDD and GND, it ideally consumes only dynamic switching power.

## Page 142: 3.4 Deep Submicrometer Device Design Issues

# 3.4 Deep Submicrometer Device Design Issues
Deep submicrometer (DSM) technology refers to CMOS devices with channel lengths below 0.25 μm, and particularly in modern technologies below 100 nm.
Although scaling down device dimensions improves speed, packing density, and performance, it also introduces several serious design challenges due to short-channel effects, increased electric fields, quantum mechanical phenomena, and variability issues.
As the physical dimensions approach nanometer scale, classical device assumptions no longer hold, and leakage as well as reliability concerns become dominant factors in device design.
Dr. Aruru Sai Kumar , VIT-AP

## Page 143: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
i) Short-Channel Effects (SCE):
As the channel length decreases, the gate gradually loses complete electrostatic control over the channel region, and the influence of the source and drain depletion regions becomes significant.
In long-channel devices, the electric field distribution is primarily one-dimensional and controlled by the gate; however, in short-channel devices, two-dimensional field effects dominate, causing threshold voltage variations and leakage.
One important effect is threshold voltage rolloff, where the threshold voltage decreases as channel length reduces because part of the depletion charge in the channel is shared by the source and drain junctions.
This reduces the amount of charge that the gate must invert, thereby lowering the threshold voltage.
Dr. Aruru Sai Kumar , VIT-AP

## Page 144: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
Another major issue is Drain-Induced Barrier Lowering (DIBL), where a high drain voltage reduces the potential barrier at the source-channel junction, effectively lowering the threshold voltage and increasing subthreshold leakage current. As a result, the OFF-state current increases significantly in scaled devices.
In extreme scaling, punchthrough occurs when the source and drain depletion regions merge, creating a direct current path even when the gate voltage is zero. This results in large leakage current and degradation of subthreshold slope.
Dr. Aruru Sai Kumar , VIT-AP

## Page 145: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
ii) Increased Leakage Currents:
In deep submicrometer devices, leakage current becomes a major contributor to total power dissipation, often comparable to dynamic switching power.
The most dominant component is subthreshold leakage, which increases exponentially as threshold voltage is reduced for performance improvement. Since subthreshold current depends exponentially on (VGS –Vth), even small reductions in threshold voltage cause large increases in leakage.
Another serious issue is gate oxide tunneling leakage, which arises because oxide thickness is aggressively scaled below 3–4 nm.
In such thin oxides, electrons can directly tunnel through the SiO₂ layer, destroying the assumption of infinite gate input impedance and increasing static power consumption.
Dr. Aruru Sai Kumar , VIT-AP

## Page 146: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
High electric fields in heavily doped junctions also cause band-to-band tunneling (BTBT), increasing reverse-bias junction leakage.
Additionally, Gate-Induced Drain Leakage (GIDL) occurs in the gate–drain overlap region due to high electric fields, especially when the gate is negatively biased and the drain is at high voltage.
Thus, leakage current management becomes a critical design concern in DSM technologies.
Dr. Aruru Sai Kumar , VIT-AP

## Page 147: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
iii) High Electric Field Effects:
As dimensions shrink, electric fields inside the transistor increase significantly because supply voltage scaling does not perfectly track dimension scaling.
High electric fields cause hot carrier injection, where energetic carriers are injected into the oxide, degrading device reliability over time.
Impact ionization and avalanche multiplication can also occur near the drain region, increasing substrate current and reducing device lifetime.
High fields near the oxide interface further increase gate leakage and oxide degradation.
Dr. Aruru Sai Kumar , VIT-AP

## Page 148: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
iv) Velocity Saturation and Mobility Degradation:
In short-channel devices, carriers quickly reach their saturation velocity due to high lateral electric fields.
As a result, the drain current becomes less dependent on channel length, reducing the performance benefit expected from scaling.
Furthermore, strong vertical electric fields near the Si–SiO₂ interface cause surface scattering of carriers, reducing mobility.
This mobility degradation reduces drive current and slows switching speed.
Dr. Aruru Sai Kumar , VIT-AP

## Page 149: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
v) Increased Power Density and Thermal Issues:
As transistor density increases dramatically in DSM technologies, more devices operate within a smaller area, leading to higher power density and heat generation.
Elevated temperatures further increase subthreshold leakage and degrade reliability. Therefore, thermal management becomes an essential part of deep submicrometer design.
vi) Variability and Process Fluctuations:
At nanometer dimensions, device performance becomes highly sensitive to small process variations.
Random dopant fluctuations, line-edge roughness, and oxide thickness variations cause significant threshold voltage variability.
This variability reduces yield and complicates circuit design, requiring statistical design techniques.
Dr. Aruru Sai Kumar , VIT-AP

## Page 150: Deep Submicrometer Device Design Issues

# Deep Submicrometer Device Design Issues
viii) Quantum Mechanical Effects:
When device dimensions approach nanometer scale, quantum mechanical phenomena become significant.
Carrier quantization occurs in the channel, modifying threshold voltage. Direct tunneling increases gate leakage.
Classical device models must be modified to include quantum corrections.
ix) Interconnect and Parasitic Effects:
As devices shrink, interconnect resistance and capacitance increase due to thinner metal lines and closer spacing.
RC delay becomes comparable to transistor switching delay. Crosstalk and signal integrity issues also become more severe.
Dr. Aruru Sai Kumar , VIT-AP

# Deep Submicrometer Device Design Issues
x) Reliability Concerns:
Deep submicrometer devices suffer from several reliability issues such as:
Hot carrier degradation
Bias Temperature Instability (BTI)
Time-Dependent Dielectric Breakdown (TDDB)
Electromigration
These effects limit long-term device performance and lifetime.

Performance Evaluation:
Among various adder architectures, the Ripple Carry Adder (RCA) requires the smallest hardware area and provides satisfactory performance when the input data is random.
However, the delay of the RCA is strongly influenced by the length of the carry propagation path, which makes it less suitable for circuits with non-random input operands.

2. Carry Look-Ahead Adders (CLA)
In a Ripple Carry Adder (RCA), the carry must propagate sequentially from one stage to the next, causing the delay to increase linearly with the number of bits (n).
This delay can be reduced by generating carry signals in parallel instead of sequentially, which is the main idea behind the Carry Look-Ahead Adder (CLA).
In the CLA architecture, carry signals are generated simultaneously using look-ahead logic based on propagate (P) and generate (G) signals.
Due to this parallel carry computation, the delay of the CLA grows logarithmically with the number of bits, approximately O(log n), which significantly reduces the carry propagation delay.
However, this improvement in speed comes at the cost of increased hardware complexity, since CLA requires a larger number of logic gates, resulting in higher area and power consumption.

Serial-Parallel multipliers:
The serial-parallel multiplier serves as a good trade-off between the time-consuming serial multiplier and the area-consuming parallel multipliers.
These multipliers are used when there is a demand for both high speed and small area.
In a device using the serial-parallel multiplier, one operand is entered serially and the other is stored in parallel with a fixed number of bits.
The resultant enhancement in the processing speed and the chip area will become more significant when a large number of independent operations are performed.

4. Introduction to WallaceTree Multiplier.
Booth’s algorithm reduces the number of partial products approximately by half, making it efficient for signed multiplication.
However, as the operand size increases (such as 32-bit and above), the generated partial products become significantly wider, leading to increased complexity and delay.
This results in performance degradation in large multipliers, even when using modified Booth techniques.
In contrast, the Wallace tree multiplier improves performance by reducing partial products more efficiently using multi-input compressors, which allow several partial products to be added simultaneously.
This parallel reduction significantly enhances speed and makes the Wallace tree more suitable for high-bit-width multiplication.

## Page 137: Types of Multiplier Architectures

# Types of Multiplier Architectures
Introduction to WallaceTree Multiplier.
Process:
In general, the Wallace tree multiplication process begins by generating partial products, which are then reduced using a set of counters (carry-save adders) that combine multiple inputs without propagating carries.
This produces an intermediate matrix consisting of sum and carry outputs. In subsequent stages, additional counters further reduce this matrix in parallel until only two rows remain.
Finally, these two rows are added using a carry propagate adder to obtain the final product.
By postponing carry propagation until the last stage, this approach significantly improves speed, and the overall performance depends on the number of reduction levels in the tree.
Dr. Aruru Sai Kumar , VIT-AP

4:2 compressors :
The primary advantage of tree multipliers is that their speed improves logarithmically with respect to the operand length, unlike iterative array multipliers where the delay increases linearly with operand size.
This makes tree-based architectures significantly faster for large-bit multiplications.
Additionally, the use of 4:2 compressors enhances design efficiency by reducing four input bits of the same weight into two outputs, resulting in a more regular and structured layout compared to traditional 3:2 counters.
This improved regularity helps in achieving better performance and easier implementation in high-speed multiplier designs.
