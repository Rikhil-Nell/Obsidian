## Applications of Monostable Multivibrator

### 1. Ramp Generator

A **linear ramp** (sawtooth) is generated by replacing the charging resistor R with a **constant current source** (transistor $Q_L$).

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s15_img1.png]]

When a capacitor is charged by constant current $i$:

$$V_C = \frac{i \cdot t}{C}$$

This gives a **linear ramp** instead of the exponential charging with a resistor.

The transistor $Q_L$ acts as a constant current source. Using KVL from base to emitter:

$$i = \frac{V_{CC} - V_{BE}}{R_E}$$

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s15_img2.png]]

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s15_img3.png]]

### 2. Frequency Divider

A monostable can function as a **frequency divider** when triggered by a continuous square wave.

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s17_img1.png]]

**How it works:**
- The timing interval $T_{mono}$ is set to be **greater than** the period of the input square wave
- First negative edge triggers the monostable (output goes HIGH)
- Second negative edge arrives while monostable is still in quasi-stable state -- **ignored**
- Third negative edge arrives after monostable returns to stable state -- triggers again
- Result: output frequency = fraction of input frequency

$$\boxed{f_{out} = \frac{f_{in}}{n}}$$

Where $n$ depends on the ratio of $T_{mono}$ to the input period.

### 3. Pulse Width Modulator (PWM)

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s18_img1.png]]

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s18_img2.png]]

**How it works:**
- A modulating signal is applied to **pin 5** (control voltage)
- This alters the upper comparator threshold (normally $\frac{2}{3}V_{CC}$)
- Trigger pulses applied to pin 2 produce output pulses
- The **frequency** remains constant (determined by trigger)
- The **pulse width** (duty cycle) varies with the modulating signal

When the modulating signal increases the threshold, the capacitor takes longer to reach it, producing a **wider** pulse. When it decreases, the pulse becomes **narrower**.

## Applications of Astable Multivibrator

### 4. FSK (Frequency Shift Keying) Generator

FSK transmits binary data using **two different frequencies** for logic 0 and logic 1.

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s19_img1.png]]

**Circuit operation:**
- 555 configured in astable mode with fixed frequency $f_1$
- Digital input (e.g., 150 Hz binary data) controls transistor $Q_M$
- **Input HIGH**: $Q_M$ OFF -- 555 oscillates at normal frequency $f_1$
- **Input LOW**: $Q_M$ ON -- connects $R_C$ in parallel with $R_A$, changing the effective resistance to $R_A \| R_C$
- New frequency $f_2$ is generated due to reduced resistance

$$f_1 = \frac{1.44}{(R_A + 2R_B)C}$$

$$f_2 = \frac{1.44}{(R_A \| R_C + 2R_B)C}$$

The output alternates between $f_1$ and $f_2$ as the digital input switches.

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s19_img2.png]]

### 5. Schmitt Trigger using 555 Timer

The 555 can function as a **Schmitt trigger** with fixed threshold levels.

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s20_img1.png]]

**Circuit setup:**
- Pins 2 and 6 connected together (input)
- Biased at $V_{CC}/2$ through a resistive divider ($R_1 = R_2$)
- Input signal applied through a coupling capacitor

**Threshold levels:**
- Upper threshold (UC): $\frac{2}{3}V_{CC}$
- Lower threshold (LC): $\frac{1}{3}V_{CC}$

**Operation:**
- When input exceeds $\frac{2}{3}V_{CC}$: UC triggers, output goes LOW
- When input drops below $\frac{1}{3}V_{CC}$: LC triggers, output goes HIGH
- Hysteresis = $\frac{2}{3}V_{CC} - \frac{1}{3}V_{CC} = \frac{V_{CC}}{3}$

A sine wave input of sufficient amplitude (peak-to-peak > $\frac{V_{CC}}{3}$) produces a clean square wave output.

![[WINSEM2025-26_ECE3001_ETH_AP2025264001037_2026-03-11_Reference-Material-I_s20_img2.png]]

## Summary Table

| Application | Mode | Key Feature |
|-------------|------|-------------|
| Ramp Generator | Monostable | Constant current replaces R for linear ramp |
| Frequency Divider | Monostable | $T_{mono}$ > input period, divides frequency |
| PWM | Monostable | Pin 5 modulates threshold, varies pulse width |
| FSK Generator | Astable | Transistor switches $R_C$ in/out for two frequencies |
| Schmitt Trigger | -- | Pins 2&6 tied, thresholds at $\frac{1}{3}$/$\frac{2}{3}V_{CC}$ |

## Self-Check Questions

> [!question]- In a PWM circuit, what remains constant -- frequency or duty cycle?
> Frequency remains constant (set by trigger pulses). The duty cycle varies based on the modulating signal at pin 5.

> [!question]- How does the FSK generator produce two different frequencies?
> When $Q_M$ is OFF: normal astable frequency. When $Q_M$ is ON: $R_C$ parallels $R_A$, reducing resistance and increasing frequency. Binary data controls $Q_M$.

> [!question]- What is the hysteresis of a 555 Schmitt trigger with $V_{CC} = 12V$?
> $V_H = \frac{2}{3}(12) - \frac{1}{3}(12) = 8 - 4 = 4V$
