Learns from being given **"right answers"**.

| **Input**         | **Output**             | **Application**     |
| ----------------- | ---------------------- | ------------------- |
| email             | spam? (0/1)            | spam filtering      |
| audio             | text transcripts       | speech recognition  |
| English           | Spanish                | machine translation |
| ad, user info     | click (0/1)            | online advertising  |
| image, radar info | position of other cars | self-driving cars   |
| image of a phone  | defect (0/1)           | visual inspection   |

# Supervised
- Regression: Housing price prediction: predicting a number from infinitely many possible outputs
- Classification: It predicts categories in which and input belongs

# Unsupervised
- In supervised the model learns from that data that we have labelled, but if the data is something that is too tedious to label, or there are many metrics to label to a single a input and or we require to find some categories unknown to naked human eye, we use unsupervised learning
- clustering: recommendation algorithms
- Anomaly Detection: Fraud Deduction
